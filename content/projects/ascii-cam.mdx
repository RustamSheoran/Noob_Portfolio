# ASCII-Cam

Transform your camera feed into real-time ASCII art. I built this as a fun project to explore real-time image processing and the creative possibilities of ASCII art.

## Features
- **Real-Time Rendering**: Live ASCII conversion at 60+ FPS.
- **High-Quality Capture**: Export 4K resolution ASCII art images.
- **Customization**: 5 character sets, adjustable font size, and color modes.
- **Camera Controls**: Snapshot export, video recording (WebM), and camera switching.

## Tech Stack
- **Framework**: React 19
- **Build Tool**: Vite
- **Rendering**: Canvas API
- **API**: MediaStream API
- **Styling**: Tailwind CSS
